Privacy & Data Retention

SecureChat stores only encrypted ciphertext — the server operator cannot read your messages. However, the following metadata is permanently logged:

  • Account creation and last login timestamps
  • Connection and disconnection events
  • Anonymised IP address hashes (one-way only, not reversible)
  • Message routing metadata (sender → recipient identifiers, timestamps)

Law Enforcement

In response to a valid legal order, the operator will provide available metadata logs to law enforcement. Message content cannot be provided as it is encrypted client-side and the server does not possess decryption keys.
